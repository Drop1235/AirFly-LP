# 会場販売（大会会場での受付）セットアップ・運用ガイド

## 仕組みの概要

```
[お客様のスマホ]  会場QR（?venue=大会ID）→ 商品選択（会場限定15%OFF）→ 注文確定
        │                                         │ Netlify: venue-create-order
        │                                         ▼  （価格をサーバーで計算・受付番号を採番）
        │                               Firestore: venue_orders（status: unpaid）
        ▼                                         │ リアルタイム表示
  受付番号画面をスタッフに提示 ─────────▶ [スタッフ] 管理者メニュー → 会場受付
                                                  │ 配送/手渡しを選び、現金 or Square を受領
                                                  │ Netlify: venue-confirm-payment
                                                  ▼
                                         status: paid → GAS（スプシ1行追加＋お客様へ注文詳細メール）
```

- 未払いの注文は Firestore にのみ保存され、**スプレッドシートには支払済になった注文だけ**が記録されます（Web の Stripe 決済と同じ考え方）。
- 大会期間が過ぎた未払い注文は確定できず、自動でキャンセル扱いになります（スプシにも載りません）。
- 送料：配送の商品が1点でもあれば 600円。全商品を手渡しにした場合は 0円。
- 会場では Web クーポンは使えません（会場限定15%OFFのみ）。

## 1. 初回セットアップ（本番反映前に必要な作業）

### 1-1. Firebase サービスアカウントを Netlify に登録
1. Firebase コンソール → プロジェクトの設定 → サービスアカウント → 「新しい秘密鍵を生成」で JSON をダウンロード
2. Netlify → Site configuration → Environment variables に以下を追加（JSON の値をそのまま転記）
   - `FIREBASE_CLIENT_EMAIL` … JSON の `client_email`
   - `FIREBASE_PRIVATE_KEY` … JSON の `private_key`（`-----BEGIN PRIVATE KEY-----` から末尾まで全部）
   - ※ JSON を丸ごと入れたい場合は `FIREBASE_SERVICE_ACCOUNT` でも可（ただし Netlify Functions の環境変数は合計 4KB 制限があるため、上の2つに分ける方法を推奨）
3. ダウンロードした JSON ファイルは共有・コミットしないこと

既存の `GAS_WEB_APP_URL` / `GAS_SECRET_TOKEN` はそのまま使います。

### 1-2. Firestore セキュリティルールに追記
Firebase コンソール → Firestore Database → ルール に、既存ルールを残したまま以下を追加してください。

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // （既存の coupons / mail_list などのルールはそのまま）

    function isVenueAdmin() {
      return request.auth != null && request.auth.token.email == 'hanks@tempmachi.com';
    }

    // 大会情報：お客様の画面が開催日判定のために読む。登録・削除は管理者のみ
    match /venue_events/{eventId} {
      allow read: if true;
      allow write: if isVenueAdmin();
    }

    // 会場の注文：管理者のみ閲覧。書き込みはサーバー（Netlify Functions）経由のみ
    match /venue_orders/{orderId} {
      allow read: if isVenueAdmin();
      allow write: if false;
    }
  }
}
```

### 1-3. スプレッドシートに見出しを追加
1行目の K〜O 列に以下の見出しを追加してください（A〜J 列は従来どおり）。

| 列 | 見出し | Web注文 | 会場注文 |
|---|---|---|---|
| K | 販売チャネル | `Web` | `会場: 大会名` |
| L | 受付番号 | （空） | `A-001` など |
| M | 支払方法 | `クレジットカード(Stripe)` | `現金` / `Square` |
| N | 受取方法 | `配送` | `1:配送 / 2:手渡し` など |
| O | 入力者 | `お客様` | `お客様` / `スタッフ代理` |

- D列（注文内容）では、会場で手渡しした商品に `【手渡し】` が付きます。
- 全商品が手渡しの注文は、J列（ステータス）が `手渡し完了（手配不要）` になります。

### 1-4. GAS を再デプロイ
1. Apps Script エディタで `Code.gs` を最新の内容に置き換えて保存
2. 「デプロイ」→「デプロイを管理」→ 既存のデプロイの鉛筆アイコン → バージョン「新バージョン」→「デプロイ」
   - ※「新しいデプロイ」を作ると URL が変わるので、必ず既存デプロイを編集してください

「LINEで代理店へ送信」は、`【手渡し】` の商品と `手渡し完了（手配不要）` の行を自動で除外します。

## 2. 大会ごとの準備

1. LP を `?admin=true` 付きで開き、管理者メニューにログイン
2. 「会場販売（大会）」で 大会名・開催日（初日／最終日）・受付番号の頭文字 を入力して「大会を登録」
3. 一覧の「URL・QR」→「印刷用ページ」で QR を印刷し、ブースに掲示
   - 会場URLは開催日のみ有効（それ以外の日は通常のWeb販売ページとして表示）

## 3. 当日の運用（スタッフ1名想定）

1. タブレットで LP（`?admin=true`）を開き、管理者メニュー →「受付を開く」
2. お客様がQRから注文 → 受付番号画面を提示 → 会場受付の「未払い」に自動で表示される
3. 受付番号の注文を選び、在庫から渡す商品だけ「手渡し」に切り替え（送料は自動計算）
4. 支払方法を選択
   - 現金：預かり金額を入力 → お釣りを確認 →「現金で受領」
   - Square：表示金額を Square で決済（メモに受付番号）→「Square決済完了」
5. 支払済になると、スプシに記録され、お客様に注文詳細メールが自動送信される
   - 送信に失敗した場合は「支払済」タブで「要再送」と表示されるので「再送する」を押す
6. スマホを持っていないお客様は「代理で注文を入力」から同じ画面で入力 → 確定後そのままお会計画面へ
